# Indiana Code MCP

Unofficial hosted MCP for Indiana legal text. **Not legal advice.**
Not an official publication. Not a citator.

**Connect:** [https://mcp.openindianalaw.org/mcp](https://mcp.openindianalaw.org/mcp)

```json
{
  "mcpServers": {
    "indiana-code": {
      "url": "https://mcp.openindianalaw.org/mcp"
    }
  }
}
```

Landing, terms, docs, and privacy: [mcp.openindianalaw.org](https://mcp.openindianalaw.org).
Verify every citation at [iga.in.gov](https://iga.in.gov/laws/ic/downloads).

This repository is the **public package card** (how to connect, license,
and what the hosted tool does not cover). It is not the working tree,
not the store, and not the harvest scripts.

Coverage limits: [NOT_COVERED.md](NOT_COVERED.md).
Support: [issues](https://github.com/open-indiana-law/indiana-code/issues).
